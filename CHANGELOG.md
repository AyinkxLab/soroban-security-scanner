## [Unreleased]

### Added

- Initial monorepo foundation: Cargo workspace with `soroban-scan-core` (library)
  and `soroban-scan-cli` (binary).
- Core `ScanError` type and version helpers.
- Initial CLI bootstrap exposing `soroban-scan version`.
- Project governance documents: README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY,
  CHANGELOG, LICENSE.
- Architecture documentation and ADR-0001 (Rust core, Python tooling).
- Security threat model and security model documentation.
- GitHub issue templates, pull request template, and CI workflow.
- `docs/PROJECT_STATUS.md` progress tracker.
