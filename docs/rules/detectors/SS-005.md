# SS-005 — Unsafe code in a Soroban contract

- **Severity:** medium
- **Confidence:** high
- **Category:** unsafe

## Problem

Contract source contains an `unsafe` block or expression. Soroban contracts
rarely require `unsafe`; when present it bypasses Rust's safety guarantees and
can introduce undefined behavior.

## How it is detected

Visits the parsed file and reports every `unsafe` block/expression with its
location. Only applies to confirmed Soroban projects.

## Limitations

- Reports usage, not a proven bug.
- Does not evaluate whether the unsafe code is sound.

## False positives

- Deliberate, audited, and well-documented `unsafe` used for a justified
  low-level operation.

## Remediation

Remove `unsafe` if possible. If required, isolate it in a small documented
function, prove its invariants, and test it directly.
