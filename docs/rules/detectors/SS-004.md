# SS-004 — Panic-prone construct in a contract entry point

- **Severity:** low
- **Confidence:** medium
- **Category:** error-handling

## Problem

A contract entry point calls `unwrap`, `expect`, `panic!`, `todo!`,
`unimplemented!`, or `unreachable!`. In Soroban these abort the invocation and
roll back state. When reachable from normal input, a recoverable error becomes a
failed transaction (a denial of service).

## How it is detected

Reports method calls named `unwrap`/`expect` and macro invocations named
`panic`/`todo`/`unimplemented`/`unreachable` inside a public `#[contractimpl]`
function. `unwrap_or`/`unwrap_or_default` are not reported.

## Limitations

- Does not determine reachability, so unreachable panics are still reported.
- Treats all panic sites equally, regardless of severity.

## False positives

- Panics on genuinely unreachable internal invariants.
- Panics that are impossible for callers to trigger.

## Remediation

Return a `Result` with a typed contract error so callers can handle failure.
Replace `unwrap`/`expect` with `?`, `unwrap_or`, or explicit matching.
